# price-comparator
An attempt to scrap websites to compare prices for the same products

## Scrapers
### MATHOM
Homepage: [MATHOM](https://mathom.es/)

For this shop, we scrap the latest games; and all the pages of offers. The offers
include from latest units of stock to returned and to even damaged units.
### DUNGEON MARVELS
Homepage: [DUNGEON MARVELS](https://dungeonmarvels.com)

For this shop, we scrap the games in discount. As with the [MATHOM](#MATHOM)
it includes latest units, returned and damaged.
